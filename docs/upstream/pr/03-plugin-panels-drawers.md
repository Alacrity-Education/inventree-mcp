Title: Render plugin panels in the group and user drawers; export RoleTable from the UI library

## Motivation

The backend already accepts `target_model` `group` and `user` for plugin UI features, but `GroupDrawer` and `UserDrawer` (Settings → Users / Groups) have no injection point, so a plugin cannot add anything to the group or user editor. The concrete case: a plugin that keeps a second, more restrictive permission table per group (for an MCP endpoint) wants to show it next to the core roles table.

## Changes

- `GroupTable.tsx` / `UserTable.tsx`: `usePluginPanels({ model: ModelType.group | ModelType.user, id, instance, reloadFunc })`, called before the early returns so the hook order is stable. Each panel renders as an extra `Accordion.Item` after the existing ones, using the same `PluginPanelContent` element `PanelGroup` renders.
- `RoleTable` moves from `src/components/items/` to `lib/components/RoleTable.tsx` and is exported from `lib/index.ts` together with `RuleSet`. New optional props: `endpoint` (default `ApiEndpoints.ruleset_list`), `onSave` (override, receives the edited rulesets) and `api` (Axios instance for the default save, because the library must not import the app's `App`). Core call sites (`GroupDrawer`, `GroupDetail`) pass `api`; plugins pass `context.api`. Core behaviour is unchanged.
- The two `Trans` usages became `t` template strings (the library only uses `@lingui/core/macro`).
- `lib/CHANGELOG.md` entry.
